# Web-based Hospital Management System (WHMS)

A comprehensive MERN stack application for managing hospital operations including patient records, doctor schedules, appointments, and administrative tasks.

## Features
- 🔐 User Authentication (Admin, Doctor, Patient roles)
- 👥 Patient Management System
- 👨‍⚕️ Doctor Profile Management
- 📅 Appointment Scheduling
- 📊 Dashboard with Real-time Statistics
- 💊 Medicine Inventory (Future Enhancement)
- 💰 Billing System (Future Enhancement)
- 📱 Responsive Design

## Tech Stack
- **Frontend**: React.js, CSS3
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT
