🏥 Hospital Management System

A comprehensive MERN stack application for managing hospital operations

🎯 Project Overview

This Hospital Management System is a full-stack web application built with the MERN stack (MongoDB, Express.js, React.js, Node.js). It provides a complete solution for managing hospital operations including patient records, doctor schedules, appointments, and administrative tasks.

👨⚕️

Doctor Management

Manage doctor profiles, specializations, schedules, and appointment tracking

👥

Patient Records

Comprehensive patient management with medical history and appointment booking

📅

Appointment System

Real-time appointment scheduling with status tracking and management

🔐

Role-Based Access

Secure authentication with Admin, Doctor, and Patient role permissions

🎮 How to Run the Project

Backend Setup:

cd backend npm install npm run dev

Frontend Setup:

cd frontend npm install npm start

Access: Frontend at http://localhost:3000 | Backend API at http://localhost:5000
